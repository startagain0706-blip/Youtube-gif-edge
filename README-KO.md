🎬 YouTube GIF Feature for Microsoft Edge

유튜브 댓글 창과 실시간 채팅(라이브 챗)에서 기본 GIF 공유 기능을 복원하고 활성화해 주는 가볍고 깔끔한 Microsoft Edge 확장 프로그램입니다.

✨ 주요 기능

기본 UI 통합: 유튜브 댓글 입력창 및 실시간 채팅창의 이모지 선택기 바로 옆에 세련된 [GIF] 버튼을 자연스럽게 추가합니다.

간편한 검색 및 전송: 탭을 전환하거나 링크를 복사할 필요 없이 유튜브 화면에서 바로 애니메이션 GIF를 검색하고 전송할 수 있습니다.

엣지 최적화 (Manifest V3): 최신 브라우저 확장 프로그램 표준으로 제작되어 빠른 속도와 최소한의 메모리 사용량을 보장합니다.

프라이버시 보호: 데이터 수집이나 추적 없이 완전히 클라이언트 사이드에서만 작동합니다.

🚀 설치 가이드

본 프로젝트는 오픈소스 프로그램으로, 개발자 모드를 통해 Microsoft Edge에 직접 간편하게 설치할 수 있습니다:

1단계: 다운로드 및 압축 해제

이 저장소를 ZIP 파일로 다운로드합니다 (초록색 Code 버튼 ➔ Download ZIP 클릭).

다운로드한 압축 파일을 컴퓨터의 원하는 폴더에 해제합니다.

2단계: Microsoft Edge에 확장 프로그램 로드하기

Microsoft Edge를 실행하고 주소창에 edge://extensions/ 주소를 입력하여 이동합니다.

Turn on the Developer mode switch located at the bottom of the left sidebar.

Click the Load unpacked button that appears at the top.

Select the extracted folder (desktop-gifs-edge-en, desktop-gifs-edge-ko, or the main project folder).

Installation Complete!

💡 사용 방법

Microsoft Edge에서 유튜브(https://www.youtube.com)에 접속합니다.

아무 영상이나 클릭한 후 댓글 창으로 스크롤하거나 실시간 채팅을 엽니다.

댓글 입력창 내부를 클릭합니다.

표준 이모지 아이콘 바로 옆에 나타나는 [GIF] 버튼을 확인합니다.

버튼을 클릭하고 원하는 GIF를 검색하여 간편하게 업로드하세요!

문제 해결 (Troubleshooting): GIF 버튼이 바로 나타나지 않는 경우, 유튜브 페이지를 새로고침하거나 edge://extensions/ 페이지에서 확장 프로그램을 껐다가 다시 켜보세요.
