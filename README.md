🎬 YouTube GIF Feature for Microsoft Edge

A lightweight, seamless Microsoft Edge extension that restores and unlocks the native GIF sharing feature in YouTube comments and live chats.

✨ Features

Native UI Integration: Seamlessly injects a sleek [GIF] button right next to the emoji picker in YouTube comment input boxes and live chats.

Instant Search & Send: Search and share animated GIFs directly on YouTube without switching tabs or copying image links.

Edge-Optimized (Manifest V3): Built with modern browser extension standards for blazing-fast performance and minimal memory footprint.

Privacy First: Operates entirely client-side with zero data collection or tracking.

🚀 Installation Guide

Since this is an open-source project, you can easily load it into Microsoft Edge via Developer Mode:

Step 1: Download & Extract

Download this repository as a ZIP file (click the green Code button ➔ Download ZIP).

Extract the downloaded archive to a folder on your computer.

Step 2: Load into Microsoft Edge

Open Microsoft Edge and navigate to edge://extensions/

Turn on the Developer mode switch located at the bottom of the left sidebar.

Click the Load unpacked button that appears at the top.

Select the extracted folder (desktop-gifs-edge-en, desktop-gifs-edge-ko, or the main project folder).

Installation Complete!

💡 How to Use

Open YouTube (https://www.youtube.com) in Microsoft Edge.

Go to any video and scroll down to the Comment Section or open a Live Chat.

Click inside any comment input box.

Look for the [GIF] button appearing right next to the standard emoji icon.

Click the button, search for your favorite GIF, and post it instantly!

Troubleshooting: If the GIF button does not appear immediately, try refreshing the YouTube page or toggling the extension off and on in edge://extensions/.
